# dapamede.com

Personal academic site of Theo Dapamede, MD, PhD — https://www.dapamede.com

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template
(updated to the upstream version of November 2026) and deployed to GitHub Pages by
`.github/workflows/jekyll.yml` on every push to `master`.

- **About page:** `_pages/about.md`
- **Sidebar profile and site settings:** `_config.yml`
- **Header menu:** `_data/navigation.yml`
- **Research highlights:** one Markdown file per highlight in `_highlights/` (front matter: `title`, `date`, `permalink`, `excerpt`, and optional `og_image` for a per-post share card in `images/highlights/`). Listed on `/highlights/`, newest first.
- **CV:** `files/Dapamede_CV.pdf` is pushed automatically by the build workflow in the private CV repo — do not edit it by hand.
- **Link-preview image:** `images/og-image.png`
